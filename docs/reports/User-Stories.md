# User Stories

## Epic 1 – Authentication

### US-01
**As a** Cloud Administrator,  
**I want** to log into the application,  
**So that** I can securely access CloudShield.

### US-02
**As a** user,  
**I want** to log out securely,  
**So that** unauthorized users cannot access my session.

### US-03
**As a** user,  
**I want** my authentication to be validated before accessing the dashboard,  
**So that** only authorized users can use the application.

---

## Epic 2 – Dashboard

### US-04
**As a** Cloud Administrator,  
**I want** to view a dashboard summary,  
**So that** I can quickly understand the status of my cloud infrastructure.

### US-05
**As a** user,  
**I want** to see key metrics displayed graphically,  
**So that** I can monitor cloud usage efficiently.

### US-06
**As a** user,  
**I want** to navigate easily between different modules,  
**So that** I can perform tasks quickly.

### US-07
**As a** user,  
**I want** the dashboard to be responsive,  
**So that** I can use it on different screen sizes.

---

## Epic 3 – Security Findings

### US-08
**As a** Security Analyst,  
**I want** to view all detected security findings,  
**So that** I can identify vulnerabilities.

### US-09
**As a** Security Analyst,  
**I want** to filter findings based on severity,  
**So that** I can prioritize remediation.

### US-10
**As a** Cloud Administrator,  
**I want** to view resource-specific security issues,  
**So that** I know which services require attention.

### US-11
**As a** Security Analyst,  
**I want** to monitor the status of security findings,  
**So that** I can track unresolved issues.

---

## Epic 4 – Cost Optimization

### US-12
**As a** DevOps Engineer,  
**I want** to view cloud spending insights,  
**So that** I can monitor infrastructure costs.

### US-13
**As a** DevOps Engineer,  
**I want** to receive optimization recommendations,  
**So that** I can reduce unnecessary expenses.

### US-14
**As a** Project Manager,  
**I want** to identify underutilized resources,  
**So that** unnecessary cloud costs can be minimized.

### US-15
**As a** Cloud Administrator,  
**I want** to view estimated monthly costs,  
**So that** I can plan budgets effectively.

---

## Epic 5 – Resource Inventory

### US-16
**As a** Cloud Administrator,  
**I want** to view all cloud resources,  
**So that** I can monitor deployed infrastructure.

### US-17
**As a** Cloud Administrator,  
**I want** to search resources,  
**So that** I can quickly find a specific service.

### US-18
**As a** Cloud Administrator,  
**I want** to filter resources by service type,  
**So that** I can manage infrastructure efficiently.

### US-19
**As a** DevOps Engineer,  
**I want** to view resource details,  
**So that** I understand their current status.

---

## Epic 6 – Reports

### US-20
**As an** IT Manager,  
**I want** to generate infrastructure reports,  
**So that** I can review cloud performance.

### US-21
**As an** IT Manager,  
**I want** reports to summarize security findings,  
**So that** I can share them with stakeholders.

### US-22
**As a** Cloud Administrator,  
**I want** reports to include cost optimization recommendations,  
**So that** improvement opportunities are clearly documented.

---

## Epic 7 – Deployment & Infrastructure

### US-23
**As a** Developer,  
**I want** the application to run using Docker,  
**So that** it can be deployed consistently across environments.

### US-24
**As a** Developer,  
**I want** the project to be easy to set up locally,  
**So that** contributors can start development quickly.

### US-25
**As a** Project Team Member,  
**I want** the application architecture to support future AWS integration,  
**So that** live cloud monitoring and optimization features can be implemented in later versions.
