# Running CloudShield Locally

## Prerequisites

- Docker Desktop
- Git
- Modern web browser (Chrome, Edge, Firefox)

---

## Clone the Repository

```bash
git clone https://github.com/Nayonika-Nair/CloudShield.git
cd CloudShield
```

---

## Build the Docker Image

```bash
docker compose up --build
```

---

## Access the Application

Open your browser and navigate to

```
http://localhost:3000
```

---

## Stop the Application

```bash
docker compose down
```

---

## Current Prototype

The current version is a frontend prototype demonstrating:

- Login Page
- Dashboard
- Security Findings
- Cost Optimization
- Resource Inventory
- Reports
